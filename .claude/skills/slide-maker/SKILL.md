# スライド作成スキル

## 1. 最初に決めること（足りなければ聞く。3問まで）
- 目的: 誰に・何をしてほしいか（購入、承認、理解など）
- 枚数と時間: 指定がなければ5〜10枚
- 出力形式: 指定がなければ **.pptx**。ブラウザで見せるだけなら HTML でもよい

## 2. 構成を先に作る（1枚1メッセージ）
1. 表紙: タイトル + 一言で何の資料か
2. 課題・背景: なぜこの話か
3. 結論・提案: 一番言いたいこと（先に結論）
4. 根拠・詳細: 1枚に1論点。数字や画像で見せる
5. 具体的な手順やプラン
6. まとめ + 次のアクション（CTA）

構成案（各スライドの見出し＝言い切りの文）をユーザーに見せ、OKをもらってから作り込む。

## 3. デザインルール
- 1枚の文字は少なく。箇条書きは最大3〜5行、1行は30文字程度まで
- 見出しは「言いたいこと」を文にする（例: ×「売上」→ ○「売上は3か月で2倍になった」）
- 本文は24pt以上、見出しは36pt以上。16:9
- 色は3色まで（ベース・メイン・アクセント）。フォントは1〜2種類（日本語はゴシック系）
- 余白を広くとる。画像は大きく、端までそろえる
- 図や表、グラフにできるものは文章にしない
- 全スライドで位置・色・フォントをそろえる

## 4. 作り方
- **.pptx**: `anthropic-skills:pptx` スキルを使う。python-pptx で生成して、画像に変換して見た目を確認する
- **HTML**: 1ファイルで完結させ、矢印キーでめくれる形にする
- 作ったら必ず1枚ずつ見て、文字のはみ出し・重なり・読みにくさを直してから渡す

## 5. 渡すとき
- ファイルの場所と、全スライドの見出し一覧を短く伝える
- 直したい点を聞く（色、順番、文言、枚数）

## 6. Sakuya向けの既定
- 商品紹介: 商品写真を大きく → 特長3つ → 使用シーン → 価格・レビュー → 購入導線
- 色は商品の雰囲気に合わせる。写真が主役なので装飾は控えめにする
- 初心者向けの資料では専門用語を避け、1枚ずつ丁寧に説明する
